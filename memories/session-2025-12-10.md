## Phase 3: Edge Density Backup Detector (COMPLETED)

### Changes made to `src/lp_detector.py`:
1. **New scoring functions**:
   - `compute_edge_density()`: Compute edge density (Canny edge ratio) for ROI
   - `compute_vertical_edge_score()`: Score based on vertical edges (Sobel X)
   - `compute_contrast_score()`: Score based on image contrast (std dev)
   - `compute_plate_score()`: Combined weighted score (edge 0.4, vertical 0.3, contrast 0.3)

   - `sliding_window_detect()`: Multi-scale sliding window with score threshold

3. **Combined detection**:
   - `detect_with_edge_backup()`: Primary (contour) + backup (edge density)

## Phase 4: Character-based ROI Validation (COMPLETED)

### Changes made to `src/lp_detector.py`:
1. **Character detection functions**:
   - `detect_character_candidates()`: Find character-like connected components in ROI
     - Uses CLAHE + Otsu binarization
     - Filters by size (2-25% of ROI height)
     - Filters by aspect ratio (0.15-1.2)
     - Returns bounding boxes and debug info
   - `_find_char_components()`: Helper function for component filtering

2. **Scoring system**:
   - `compute_character_score()`: Score ROI based on character quality
     - **char_count** (weight 0.4): Expected 4-10 characters
     - **size_consistency** (weight 0.3): Character sizes should be uniform
     - **spacing_regularity** (weight 0.2): Character spacing should be consistent
     - **alignment** (weight 0.1): Characters should be vertically aligned

3. **Validation functions**:
   - `validate_plate_roi()`: Validate single ROI with character analysis
     - Returns (is_valid, score, details)
   - `filter_detections_by_characters()`: Filter list of detections by score
     - Default min_char_score=0.35
     - Returns filtered list + statistics

4. **Full pipeline**:
   - `detect_with_character_validation()`: Complete detection pipeline
     - Runs edge backup detector
     - Validates all candidates with character scoring
     - Returns validated detections + debug info
